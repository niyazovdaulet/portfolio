Flagship

Friscora

Personal finance and work schedule for iPhone—income, expenses, goals, analytics, optional bank statement import with on-device rule-based categorization, and optional schedule sharing backed by Firebase.

Built for clarity

Native SwiftUI with an MVVM-oriented structure, iOS 18+, local-first data with optional iCloud Key-Value, and Firebase only where the product needs it (schedule sharing, feedback)—not as a generic “AI backend.”

Statement categorization is deterministic on device; the codebase does not ship an in-app LLM or cloud ML over your transactions.

SwiftUI MVVM iOS 18 Firebase Unit tests
